用户（用户端账号）

用户端（/booking）有自己的账号体系：每个用户用自己的平台账号登录， 绑定自己的图书馆账号，只看得到、也只改得动自己的预约。 用户的学校凭据加密后单独保存，这一页只显示标识与状态 （学校账号、有效性、指纹前缀），不显示任何凭据值 —— 页面上拿到的数据里根本没有 Cookie / Authorization 字段。

用户端与管理员是两套账号

这一页的用户不是管理员：他们登录不了 /admin， 也看不到任何全局开关。这里的停用 / 删除 / 重置口令只作用于用户端账号， 不会锁住你自己的管理员账号。

用户口令只存 scrypt 哈希，重置后其全部会话立即作废； 学校口令从不落盘 —— 用户绑定图书馆账号时提交的口令只在那一次请求的内存里存在。
